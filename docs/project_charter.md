# Project Charter

## Project
GSIS Asset Sync Platform

## Purpose
Deliver a production-grade platform that synchronizes assets from Kaseya to Strev/Revnue with controlled transfer, autosync, observability, diagnostics, and operator tooling.

## Scope
- Backend APIs, workers, and storage
- Frontend operator dashboard and support pages
- Deployment artifacts (Docker/nginx/systemd/CI)
- Operational runbooks and maintenance scripts

## Stakeholders
- Operations team (asset transfer operators)
- Platform engineering team
- Support team
- Security/compliance reviewers

## Success Criteria
- End-to-end local run
- SOP-required APIs and pages implemented
- Matching and transfer safeguards enforced
- Autosync pipeline operational
- Basic test suite and CI checks present
